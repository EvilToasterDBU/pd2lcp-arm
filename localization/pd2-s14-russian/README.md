# Русификатор Project Diablo 2 S14

Совместимый набор локализации для PD2 S14. Таблица содержит все 3152 уникальные строки актуального `patchstring.tbl`: 2252 ключа совпали с S9: 2237 переводов переиспользованы без изменений, 15 исправлены после сравнения с английской строкой S14. Ещё 900 новых строк S14 переведены отдельно. Для всех записей проверены плейсхолдеры, цветовые коды и число переносов строк; происхождение перевода указано в `strings.tsv`.

`patchstring.tbl` нужно установить в `ProjectD2/data/local/LNG/rus/`. Набор не включает исполняемые файлы, таблицы баланса или другие файлы S9. Перевод выбирается запуском игры с `-direct`; в лаунчере для этого есть настройка «Русский язык».

## Состав

- `patchstring.tbl` — готовая таблица для PD2 S14.
- `strings.tsv` — редактируемый исходник: ключ, английская строка S14, русский перевод и происхождение перевода.
- `build_translation.py` и `tbl_format.py` — сборка таблицы и чтение/запись формата D2 `.tbl`.
- `ui-labels.tsv` — историческая таблица соответствий имён DC6 и английских подписей. Используйте её только для справки.

## Пересборка

Извлеките `data\\local\\LNG\\ENG\\patchstring.tbl` из S14 `pd2data.mpq` и русский `patchstring.tbl` из архива S9. Затем выполните:

```sh
python3 build_translation.py /path/to/S14-patchstring.tbl /path/to/S9-russian-patchstring.tbl
```

## Подписи настроек через настоящий HD Text

Используйте сборку и инструкции в `../d2gl/README.md`. В D2GL для PD2 английские DC6 распознаются по размерам и заменяются настоящим HD-текстом. Русская таблица не включала 80 модовых пунктов S14. Исправление добавляет их в таблицу D2GL и возвращает исходные DC6-сигнатуры, сохраняя ванильные шрифты, цвет, тени и выравнивание.

`build_ui_labels.py` — отключённый эксперимент с перерисовкой DC6. Его нельзя применять: он создавал текст как пиксели и нарушал распознавание ресурсов. `ui-labels.tsv` оставлен как история сопоставления файлов.

В режиме без HD Text модовые меню используют исходные английские изображения S14; русский текст добавлен в настоящий HD-рендер.
