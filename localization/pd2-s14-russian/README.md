# Русификатор Project Diablo 2 S14

Совместимый набор локализации для PD2 S14. Английская таблица S14 содержит 3278 индексированных записей и 3152 уникальных ключа. В исходнике сохранены все повторяющиеся ключи и исходный порядок строк: 2244 записи переиспользуют перевод S9, 174 записи S9 исправлены по смыслу S14, ещё 860 строк переведены для S14. Это важно: игра обращается к строкам по индексам, а схлопывание повторов сдвигает подписи предметов, умений и интерфейса. Для каждой записи проверены исходный индекс, ключ, форматные маркеры, их порядок и цветовые коды.

Также проверены все 5391 записи базовой `string.tbl` и 2818 записей `expansionstring.tbl`: порядок и соответствие ключей совпадают с английскими таблицами. Исправлены оставшиеся английские и транслитерированные строки в S14; названия модовых пунктов D2GL сверены отдельно — все 80 записей HD Text.

`patchstring.tbl` нужно установить в `ProjectD2/data/local/LNG/rus/`. Набор не включает исполняемые файлы, таблицы баланса или другие файлы S9. Перевод выбирается запуском игры с `-direct`; в лаунчере для этого есть настройка «Русский язык».

Готовый полный пакет для чистой установки S14 скачивается как `pd2-russian-s14-hd.zip` в [последнем релизе](https://github.com/EvilToasterDBU/pd2lcp-arm/releases/latest). Он включает целое дерево `ProjectD2/data` с русскими таблицами, шрифтами, UI, управлением и озвучкой; меню S14 сохраняет исходные DC6-сигнатуры, чтобы установленный D2GL мог распознавать HD-текст. Пакет локализации не заменяет `ddraw.dll` или `glide3x.dll`. Для установки скопируйте содержимое `ProjectD2` из архива в папку игры.

## Состав

- `patchstring.tbl` — готовая таблица для PD2 S14.
- `strings.tsv` — построчный исходник S14 с исходным индексом, включая повторяющиеся ключи.
- `legacy-strings.tsv` — построчные исходники базовой и дополненной таблиц Diablo II.
- `build_translation.py`, `build_legacy_translation.py` и `tbl_format.py` — сборка таблиц и чтение/запись формата D2 `.tbl`.
- `ui-labels.tsv` — историческая таблица соответствий имён DC6 и английских подписей. Используйте её только для справки.

## Пересборка

Извлеките `data\\local\\LNG\\ENG\\patchstring.tbl` из S14 `pd2data.mpq`. Затем выполните:

```sh
python3 build_translation.py /path/to/S14-patchstring.tbl
python3 build_legacy_translation.py string.tbl /path/to/ENG/string.tbl /path/to/rus/string.tbl
python3 build_legacy_translation.py expansionstring.tbl /path/to/ENG/expansionstring.tbl /path/to/rus/expansionstring.tbl
```

`strings.tsv` содержит одну запись на каждый исходный индекс. Не удаляйте повторяющиеся ключи и не сортируйте TSV по ключу.

## Подписи настроек через настоящий HD Text

S14 распознаёт пункты меню по сигнатурам DC6, а HD-текст рисует сам D2GL. Русификатор сохраняет исходные файлы меню S14 и не меняет сигнатуры; таблица строк игры переводит только текстовые ресурсы. В варианте пакета без замены D2GL DLL добавленные модовые подписи остаются на языке и в том виде, который предоставляет установленная версия игры/D2GL.

`build_ui_labels.py` — отключённый эксперимент с перерисовкой DC6. Его нельзя применять: он создавал текст как пиксели и нарушал распознавание ресурсов. `ui-labels.tsv` оставлен как история сопоставления файлов.

В режиме без HD Text модовые меню используют исходные английские изображения S14; русский текст добавлен в настоящий HD-рендер.
